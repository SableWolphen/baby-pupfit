📈 Smart progression

Work mostly at 1–2 RIR. When every work set reaches the top of the rep range with clean form, raise the weight next time. Big lower-body machines: usually +5–10 lb. Smaller machines/cables: use the smallest available jump.

If reps fall below the range, keep the weight. If performance drops for two sessions while sleep/recovery is poor, do not add weight. If joints hurt, stop that movement and swap it.

🔥 Abs are a main lift now

Abs are not a throwaway finisher. Treat the crunch machine like any other hypertrophy exercise: add reps, then load. Knee raises cover the hip-flexion/pelvic-control side. You do not need hundreds of reps or daily ab work.

⏱️ Tiny Mode • 25–35 min

Lower day: Glute Drive → Leg Press/Hack → Abduction → Ab Crunch. Upper day: Pulldown → Row → Curl → Pressdown. If you're rushed, preserve the highest-return lifts instead of rushing seven mediocre exercises.

🧠 Recovery rules

Hard sets only count when they're productive. Keep at least one full day between the two hardest lower sessions. Take an easier week if performance, motivation, soreness, and sleep all deteriorate together. More punishment is not faster growth.

Exact proportions and speed vary with anatomy, training history, nutrition, recovery, and body-fat level. Use pain-free ranges and adjust machines to fit you.
