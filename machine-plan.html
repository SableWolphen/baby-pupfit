📈 Progress rule

Keep most work sets around 1–2 reps from failure. When every set reaches the top of the rep range cleanly, add the smallest useful weight jump next time.

Priority: Ab Crunch → Glute Kickback → Hip Abduction / Leg Press → Upper body → thighs.

⏱️ Tiny Mode

Abs/glutes: Ab Crunch → Glute Kickback → Hip Abduction → Leg Press. Upper: Pulldown → Row → Curl → Pressdown.

If a machine at your EOS feels awkward or unavailable, use the closest machine pattern and keep the same rep range. Pain means stop and swap.
